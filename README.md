## 🚀 Overview

**GC** is a feature-rich, premium group chat application built to rethink how friends communicate. Featuring a beautiful, fluid UI powered by **React Native Reanimated**, it brings a suite of powerful commands and AI integrations right to your fingertips.

## 🌟 Key Features

### 🤖 GC AI & Smart Mentions
* **Rich Mention Chips**: Type `@gc` to instantly summon the AI, or `@member` to mention friends. Mentions seamlessly transform into translucent, styled chips with inline profile pictures right in your composer and chat bubbles.
* **GC AI Assistant**: An integrated AI ready to answer questions, recap missed messages, or interact with the group.

### ⚡ Power Slash Commands
Type `/` in the composer to access a suite of powerful features instantly:
- 🎭 `/anon` - Send messages anonymously.
- 📊 `/poll` - Create interactive group polls.
- 🟩 `/wordy` - Play today's daily 5-letter word puzzle together.
- ✨ `/missed` - AI recap of the chat while you were away.
- 🍵 `/tea` - Record spicy drama in real-time.
- 🧬 `/dna` - View your group's unique personality archetype.
- 🏆 `/awards` - Check out claimed awards and weekly superlatives.
- 📌 `/pinned` - Quickly browse pinned messages.
- 🖼️ `/media` - Explore shared photos, videos, and documents.
- 🗑️ `/clear` - Locally clear your chat screen for privacy.

### 💅 Premium UI & UX
* **Fluid Animations**: Utilizing `react-native-reanimated` for 60fps micro-interactions, swipe-to-reply, and smooth transitions.
* **Translucent Glassmorphism**: Stunning message bubbles that adapt to custom wallpapers and themes.
* **Tailwind CSS**: Rapid and consistent styling using `NativeWind`.

---

## 🛠️ Tech Stack

* **Framework:** React Native + Expo (SDK 54)
* **Language:** TypeScript
* **Styling:** NativeWind (Tailwind CSS) + custom Reanimated styles
* **Backend:** Supabase (Auth, Database, Realtime, Storage, Edge Functions)
* **Navigation:** React Navigation 7
* **Animations:** React Native Reanimated & Gesture Handler
* **Media:** Expo Camera, Audio, Video, Document Picker, Media Library
