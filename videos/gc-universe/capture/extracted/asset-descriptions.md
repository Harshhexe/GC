# GC source inventory

This launch film is a stylized interpretation of the locally supplied GC app rather than a literal browser recording. The signed-in UI and the workspace source are the product truth.

- `assets/gc-logo.png` — official GC Group Chat logo; launch and end-card mark.
- `assets/gc-app-logo.png` — transparent GC app logo; small-format screen and UI treatment.
- `assets/chat-background.png` — official chat visual texture; chat and AI scenes.
- `assets/group-list-background.png` — official group-list visual texture; universe opener and group-screen scenes.
- Local signed-in web app — visual reference for the chats rail, group list, group chat, Awards, and Profile. It uses dark glass surfaces with purple, cyan, amber, and rose accents.

## Source-derived screen and feature inventory

- Screens: Chats and groups, chat composer, Create, Explore, Awards, Profile, notifications, group search, pins, media/links/files, group info, group instructions, Wordy, Wordle.
- AI: in-chat `@gc`, slash commands, What Did I Miss, daily recaps, Tea Reports, AI poll drafts, daily names, weekly awards, and GC DNA.
